# elio.nvim Implementation Plan

> **For agentic workers:** After this plan is written, present the execution gate to the user (`/goal-prep` board vs inline executing-plans). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish `Xpos587/elio.nvim`, a standalone Neovim plugin that embeds Elio in a floating terminal and returns selected paths to Neovim workflows.

**Architecture:** Dependency-free Lua plugin for Neovim 0.10+ with focused modules for configuration, command/result handling, floating-window management, process lifecycle, and file actions. Elio is launched with temporary `--chooser-file` and `--cwd-file` paths; process exit dispatches current-window, split, tab, quickfix, clipboard, and cwd actions. No Elio IPC is assumed.

**Tech Stack:** Lua, Neovim Lua API (`vim.api`, `vim.fn`, `vim.uv`), Elio CLI 1.12-compatible flags, shell fixture, headless Neovim tests, StyLua, GitHub Actions, MIT license.

## Global Constraints

- Keep plugin dependency-free; do not require Kitty, Yazi, Plenary, Telescope, or Snacks.
- Support Neovim 0.10+ and current Elio CLI flags `--chooser-file` and `--cwd-file`.
- Preserve Elio as the UI; Neovim owns only terminal embedding and post-exit actions.
- Do not claim live rename/move/delete synchronization; Elio exposes no Yazi DDS/IPC equivalent.
- Use argument-list APIs or escaped command arguments; never concatenate unescaped user paths into shell commands.
- Keep all new project files ASCII unless an existing technical identifier requires another encoding.
- Do not modify `/home/michael/.config/nvim` until standalone plugin tests and smoke checks pass.
- Do not overwrite or revert existing dirty changes in `/home/michael/.config/nvim`.
- Publish only after local checks pass and target `Xpos587/elio.nvim` is confirmed available or safely creatable.

```lua
local M = {}

local function read(path)
  if not path or vim.fn.filereadable(path) ~= 1 then
    return {}
  end
  return vim.fn.readfile(path)
end

function M.read_chooser(path)
  local output = {}
  for _, line in ipairs(read(path)) do
    line = line:gsub("\r$", "")
    if line ~= "" then
      output[#output + 1] = line
    end
  end
  return output
end

function M.read_cwd(path)
  local lines = read(path)
  if not lines[1] or lines[1] == "" then
    return nil
  end
  return lines[1]:gsub("\r$", "")
end

return M
```

- [ ] **Step 3: Implement floating window**

`lua/elio/window.lua` must create a scratch terminal buffer and centered floating window, set `bufhidden = wipe`, and expose `job_id` after process startup. Use `nvim_open_win` options derived from `vim.o.lines`, `vim.o.columns`, and `floating_window_scaling_factor`. Register `VimResized` buffer autocmd to call `vim.fn.jobresize(context.job_id, height, width)` when available. `close` must close valid window, delete valid buffer, and restore `winblend`.

Core shape:

```lua
local M = {}

local function dimensions(opts)
  local factor = opts.floating_window_scaling_factor
  local width = type(factor) == "table" and factor.width or factor
  local height = type(factor) == "table" and factor.height or factor
  local max_width, max_height = vim.o.columns, vim.o.lines - (vim.o.cmdheight == 0 and 1 or 0)
  width = width <= 1 and math.floor(max_width * width) or math.min(width, max_width)
  height = height <= 1 and math.floor(max_height * height) or math.min(height, max_height)
  return width, height, math.floor((max_height - height) / 2), math.floor((max_width - width) / 2)
end

function M.open(opts)
  local width, height, row, col = dimensions(opts)
  local buffer = vim.api.nvim_create_buf(false, true)
  local window = vim.api.nvim_open_win(buffer, true, {
    relative = "editor", style = "minimal", width = width, height = height,
    row = row, col = col, border = opts.floating_window_border,
  })
  vim.bo[buffer].bufhidden = "wipe"
  vim.bo[buffer].filetype = "elio"
  vim.wo[window].winblend = opts.floating_window_winblend
  return { buffer = buffer, window = window, width = width, height = height }
end

function M.close(context)
  if context.window and vim.api.nvim_win_is_valid(context.window) then
    vim.api.nvim_win_close(context.window, true)
  end
  if context.buffer and vim.api.nvim_buf_is_valid(context.buffer) then
    vim.api.nvim_buf_delete(context.buffer, { force = true })
  end
end

return M
```

- [ ] **Step 4: Implement public lifecycle API**

`lua/elio/init.lua` merges options once in `setup`, tracks one active context, stores previous window and last path, and dispatches results after process exit. Default exit action opens one selected path in the previous window; multiple paths use the argument list. Before action dispatch, call `silent! checktime`.

Required public shape:

```lua
local M = { config = nil, active = nil, last_path = nil }

function M.setup(opts)
  M.config = require("elio.config").merge(opts)
  vim.api.nvim_create_user_command("Elio", function(command)
    M.open(command.args ~= "" and vim.fn.expand(command.args) or nil)
  end, { nargs = "?", complete = "file" })
  vim.api.nvim_create_user_command("ElioToggle", function(command)
    M.toggle(command.args ~= "" and vim.fn.expand(command.args) or nil)
  end, { nargs = "?", complete = "file" })
  vim.api.nvim_create_user_command("ElioClose", function() M.close() end, {})
end

function M.is_open()
  return M.active ~= nil and M.active.window ~= nil and vim.api.nvim_win_is_valid(M.active.window)
end
```
