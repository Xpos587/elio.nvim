# Changelog

## 0.1.0

- Embed Elio in a Neovim floating terminal.
- Return chooser and final cwd results through Elio's `--chooser-file` and `--cwd-file` flags.
- Add current-window, split, tab, quickfix, clipboard, and cwd actions.
- Add `:Elio`, `:ElioToggle`, and `:ElioClose` commands.
- Document known limitation: no live Yazi DDS/IPC synchronization.
